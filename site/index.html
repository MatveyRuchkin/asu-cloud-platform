Найди себя

Выбери своё имя, прочитай задание и узнай, с кем надо согласовывать работу.

2

Закрепи за собой Issue

Открой свою задачу → прокрути к Add a comment → напиши беру → нажми Comment. Бот назначит тебя исполнителем, если доступ к репозиторию позволяет.

3

Отправь Pull Request

Внеси изменения только в свою ветку от dev, покажи проверки, дождись ревью.
