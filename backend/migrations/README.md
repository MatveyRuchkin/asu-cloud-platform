# Миграции базы данных

Каталог для миграций Alembic (`alembic.ini` + `migrations/versions/`).

**Владелец:** DB-01 (Коптелов Владислав) совместно с BE-01 (Лаврецкий Константин).

Инициализация Alembic выполняется в рамках DB-01, после утверждения схемы в `docs/database/er.md`.
Правила: миграция только добавляет изменения, уже принятые миграции не переписываются,
все миграции применяются на чистой базе без ошибок.

Каркас создан по Issue #5 (ARCH-01).
