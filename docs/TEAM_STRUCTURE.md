## Тестирование — отдельная команда

**Юрий Найдёнов — QA Lead.** **Виктория Антонова и Голбан — QA-инженеры.** Они не переводятся в Backend или Frontend и не подчиняются их руководителям. Команда QA проверяет функциональность обоих направлений, а также выполняет технические вспомогательные задачи:

- Юрий — автоматизация проверок API, шаблон результатов тестирования и координация QA.
- Виктория — проверка пользовательских форм, сценарии тестирования и наборы входных данных.
- Голбан — проверка объявлений, вымышленные объявления в JSON и сценарии ошибок.

При необходимости QA согласовывает детали интерфейса с Алексеем Хапковым, детали API — с Константином Лаврецким. Непосредственный руководитель Виктории и Голбана — **Юрий Найдёнов**.

**Сам разработчик тоже обязан проверить свою часть** до отправки PR. QA даёт дополнительную, независимую проверку. При изменениях API или БД необходимо согласование соответствующего лида и Михаила Сергеенко.
