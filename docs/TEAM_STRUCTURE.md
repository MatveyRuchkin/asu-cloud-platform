## База данных — три участника

- Владислав Коптелов — проектирование схемы PostgreSQL, связи и миграции.
- Никита Аракчеев — тестовые SQL-данные и запросы для проверки связей.
- Юрий Найдёнов — воспроизводимые проверки миграций, внешних ключей и ограничений.

Технический руководитель и первый контакт команды — **Михаил Сергеенко**. Константин Лаврецкий согласует совместимость с Backend и API. Важно, чтобы участники не дублировали одни и те же файлы.

## Тестирование — два участника

- Виктория Антонова — тестирование регистрации/входа и подготовка тестовых данных для форм.
- Голбан — тестирование объявлений, набор примеров JSON и ошибочные сценарии.

**Найдёнов больше не входит в команду тестировщиков.** Отдельного QA Lead сейчас нет; вопросы по QA направляются Михаилу Сергеенко, а детали конкретных функций согласовываются с соответствующим разработчиком. Разработчики тоже обязаны проверять свои изменения перед PR.

Тестировщики могут выполнять небольшие вспомогательные технические задачи, например создавать тестовые наборы JSON, файлы сценариев, автоматизированные проверки и вспомогательные скрипты. Новые функции приложения им не передаются без согласования.
