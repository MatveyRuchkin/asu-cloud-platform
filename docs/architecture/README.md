# Архитектура проекта

Здесь зафиксированы технические решения команды: стек, границы модулей, схема взаимодействия и правила работы в репозитории.

| Документ | О чём |
| --- | --- |
| [decisions.md](decisions.md) | Архитектурные решения (ADR): стек, контракт, границы модулей, конвенции |
| [structure.md](structure.md) | Структура папок, владение каталогами, локальный запуск |

**Статус:** предложено техлидом (Issue #5, ARCH-01). Решения действуют для всех, пока не появится новое Issue с решением об изменении.

## Как читать

- Новый участник: сначала [decisions.md](decisions.md) (что и почему), потом [structure.md](structure.md) (где что лежит и как запустить).
- Перед началом модуля: найди в [decisions.md](decisions.md) раздел «Владение каталогами» и убедись, что не заходишь в чужую часть.
- Изменение API, БД, зависимостей или архитектуры: это отдельное Issue + согласование, а не правка в своей ветке.
