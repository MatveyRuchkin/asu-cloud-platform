# Персональные задания

У каждого участника есть одна первая Issue, описанная простым языком. Задания представлены также на сайте команды.

Чтобы найти своё задание, откройте соответствующий файл в этой папке или воспользуйтесь поиском по имени на сайте. **Работать нужно по GitHub Issue:** там фиксируются вопросы, изменения, ревью и результат.

Пока роли и контракт не утверждены, написание зависимых модулей начинать рано: допустимо готовить макеты, план файлов, схемы и вопросы.
