**Роль:** Инфраструктура: Docker Compose

**Задача:** Настроить PostgreSQL и backend через Docker Compose по согласованному каркасу

**Дедлайн:** 23 октября 2026, 23:59 МСК

## Пошагово

1. Уточнить у Константина стек backend и версию PostgreSQL
2. Создать Dockerfile для существующего backend, если каркас уже готов
3. Настроить compose.yaml для backend и PostgreSQL с постоянным volume
4. Подготовить безопасный .env.example и .dockerignore
5. Написать пошаговую инструкцию запуска и протестировать; если backend отсутствует — показать рабочую БД и описать блокер
