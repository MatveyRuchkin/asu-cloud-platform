## Задача
Подготовить автоматические проверки API и инструкцию проверки функциональности команды

## Шаги
1. Согласовать с Backend Lead один готовый API-маршрут и требования к нему
2. Подготовить минимум два сценария: корректный запрос и проверка ошибки
3. Реализовать воспроизводимый smoke-тест или Postman-коллекцию
4. Подготовить шаблон записи результата проверки для других участников QA
5. Запустить проверки и указать результаты или блокеры в Pull Request
