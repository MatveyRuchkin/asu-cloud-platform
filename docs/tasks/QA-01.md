## Пошагово

1. Уточнить у Константина, какие API-маршруты уже реализованы
2. Подготовить положительный и ошибочный сценарий одного маршрута
3. Реализовать smoke-тест или Postman-коллекцию
4. Запустить проверку и описать результаты в PR

## Критерии готовности

- [ ] Есть минимум два проверяемых сценария одного маршрута
- [ ] Проверки воспроизводимы по инструкции
- [ ] Реальный результат тестирования или блокер зафиксирован
- [ ] В PR приложен результат самостоятельной проверки и способ повторить её

Проверьте результат и откройте PR в `dev` с `Closes #НОМЕР`. Опишите проверку и укажите, если что-то заблокировано. Не изменяйте чужую часть без согласования с лидом.
