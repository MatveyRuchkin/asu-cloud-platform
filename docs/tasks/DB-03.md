# DB-03 — Найдёнов Юрий

**Роль:** Разработчик БД: проверки миграций и ограничений
**Команда:** База данных
**Руководитель:** Михаил Сергеенко
**Дедлайн:** 23 октября 2026, 23:59 МСК

## Задача
Подготовить проверки миграций PostgreSQL и ограничений целостности БД

**С кем согласовать:** Владислав Коптелов, Никита Аракчеев, Аксютин Антон, Лаврецкий Константин

## По шагам
1. Согласовать со Владиславом ключи, связи и способ запуска миграций
2. Подготовить повторяемую проверку создания пустой базы и применения миграций
3. Проверить минимум три ограничения: внешний ключ, обязательное поле, уникальность
4. Запустить проверки в тестовой PostgreSQL, при отсутствии готовых миграций документировать блокер
5. Согласовать результаты с Никитой и передать Михаилу Сергеенко на проверку

## Что сдать
`tests/database/ и docs/database/migration-checks.md`

## Критерии готовности
- [ ] Есть инструкции запуска и минимум три воспроизводимые проверки целостности
- [ ] Указаны реальные результаты проверок, ошибки или точный блокер
- [ ] Используются только тестовые данные без реальных персональных сведений
- [ ] Работа согласована с Владиславом и Михаилом Сергеенко
- [ ] В PR приложен результат самостоятельной проверки и способ повторить её

Схему и миграции готовит Владислав, тестовые SQL-запросы и данные — Никита. Юрий отвечает за отдельные воспроизводимые проверки миграций и ограничений, а не переписывает работу остальных.

## Как сдавать
Открой PR в `dev` со строкой `Closes #14` и приложи результаты проверок. Если миграций ещё нет — подготовь план, каркас и объясни, что блокирует запуск.
